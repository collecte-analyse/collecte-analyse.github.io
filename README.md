# Portfolio — NTONDELE MPELA Floriant

Site web personnel de **NTONDELE MPELA Floriant**, Économiste et Data Analyst spécialisé dans le suivi-évaluation des projets d'investissement public. Le site est hébergé via GitHub Pages à l'adresse [collecte-analyse.github.io](https://collecte-analyse.github.io/).

## Contenu du site

Le portfolio est une page unique (`index.html`) organisée en sections accessibles depuis le menu de navigation :

- **Accueil** — Présentation générale et liens vers LinkedIn, GitHub et WhatsApp.
- **À propos** — Profil professionnel : analyse de données, collecte de données, suivi & évaluation.
- **Compétences** — Outils maîtrisés avec niveau de maîtrise : Python, GitHub, Visual Studio Code, Microsoft Excel, R, Power BI, SPSS & Stata, KoboToolbox, QGIS.
- **Services** — Prestations proposées : collecte de données, analyse de données, tableaux de bord, suivi-évaluation, IA appliquée, SIG & cartographie.
- **Mes réalisations** — Six projets illustrant l'expertise (évaluation d'hôpitaux, évaluation de lycées, projet SAEP, tableaux de bord Power BI, pipeline ETL Python, IA appliquée au suivi-évaluation), chacun avec un lien vers une fiche projet PDF.
- **Formation** — Parcours académique et professionnel (Master en Économétrie Appliquée, formation IA, Python Data Analytics, Power BI, expérience au CNEEPIP), ainsi qu'une section **Certifications** avec liens vers les certificats obtenus.
- **Contact** — Coordonnées, réseaux sociaux, téléchargement du CV et formulaire de contact.

## Structure du dépôt

```
├── index.html              Page principale du site
├── style.css                Styles principaux
├── responsive.css           Adaptations mobile / tablette
├── script.js                 Interactions (menu mobile, bouton retour en haut, formulaire de contact)
├── favicon.svg / .png        Icône du site (onglet navigateur)
├── apple-touch-icon.png       Icône pour appareils Apple
├── images/                   Photos et logos utilisés sur le site
│   └── logos/                 Logos des établissements et outils (Formation)
├── projets/                  Fiches PDF des projets présentés dans "Mes réalisations"
└── CV/                       CV et certificats téléchargeables depuis le site
```

## Technologies utilisées

- HTML5 / CSS3 / JavaScript (vanilla, sans framework)
- [Font Awesome](https://fontawesome.com/) pour les icônes
- [Devicon](https://devicon.dev/) pour les icônes de compétences techniques
- [FormSubmit](https://formsubmit.co/) pour la réception des messages du formulaire de contact, sans backend
- Hébergement via **GitHub Pages**
